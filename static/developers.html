Developers

The colour signal your pebble reads is a public JSON API. There is also a Home Assistant integration, and personal API tokens for anything you build yourself.

API

  • GET /api/color-code Current and upcoming color codes. Devices sending X-Device-ID get their household's personalized signal and display settings.
  • GET /api/json Raw electricity price data.
  • GET /api/sample Sample data, for testing without hitting the live feed.
  • GET /api/sample-color-code Sample color codes.
  • GET/PUT /api/user/settings Your household profile: contract, solar, battery, display. Sign-in required.
  • GET /docs Interactive API documentation, generated from the service itself.

API tokens

For anything that needs your own data rather than the public feed. A token acts as you and never as an admin, whatever your account can do.

  1. Open your user menu on the dashboard, then Settings → Account.
  2. Name the token and create it. It is shown once; copy it then.
  3. Send it as a bearer token:
curl -H "Authorization: Bearer YOUR_TOKEN" \
     https://energypebble.tdlx.nl/api/color-code

Tokens are listed under the same settings tab, with when each was created and last used, and can be revoked there.

Home Assistant

A custom component exposes your pebble's signal as a sensor. It polls the same endpoint the physical device does, so the value is personalized to your household profile rather than the raw market price. It lives in its own repository, energy-pebble-homeassistant.

Install with HACS

  1. In HACS, open the three-dot menu and choose Custom repositories.
  2. Add https://github.com/thomaskgb/energy-pebble-homeassistant, category Integration.
  3. Install Energy Pebble, then restart Home Assistant.

Or install manually

Download the latest release unzips to custom_components/energy_pebble/

  1. Unzip it next to your configuration.yaml, so the files land in custom_components/energy_pebble/.
  2. Restart Home Assistant.

Then connect it

  1. Create a token here under Settings → Account, as above. It is shown once.
  2. In Home Assistant: Settings → Devices & services → Add integration → Energy Pebble. Paste the token, then pick which pebble to follow.

Entity

sensor.<nickname>_color holds the current color (green, yellow or red), with next_hours, signal_source, personalized and the display block as attributes.

Example automation

automation:
  - alias: Start dishwasher when the pebble turns green
    triggers:
      - trigger: state
        entity_id: sensor.kitchen_color
        to: "green"
    actions:
      - action: switch.turn_on
        target:
          entity_id: switch.dishwasher

Technical details

  • Data source: Elia Grid International, the Belgian TSO.
  • Coverage: Belgian day-ahead electricity market prices.
  • Update frequency: day-ahead prices publish around 12:45 CET; colors are committed for 8 hours so they cannot shift under you.
  • Format: JSON, with CORS enabled.
  • Caching: a fetched day is final, so days are cached and survive restarts.
