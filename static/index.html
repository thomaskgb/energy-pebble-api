How It Works

Energy Pebble fetches real-time electricity prices from Elia's grid data and converts them into simple color codes to help you optimize your energy consumption. Signed-in users tune the signal to their household (energy contract, solar panels, home battery), and their pebble follows automatically.

API Endpoints

  • GET /api/color-code Current and upcoming color codes; devices sending X-Device-ID get their household's personalized signal and display settings
  • GET /api/json Raw electricity price data
  • GET /api/sample Sample data for testing
  • GET /api/sample-color-code Sample color codes
  • GET/PUT /api/user/settings Your household profile (contract, solar, battery, display). Sign-in required
  • GET /docs Interactive API documentation

Technical Details

  • Data Source: Elia Grid International (Belgian TSO)
  • Update Frequency: Real-time with 8-hour commitment windows
  • Coverage: Belgium electricity market prices
  • API Format: JSON responses with CORS support
  • Caching: Optimized for performance and stability
